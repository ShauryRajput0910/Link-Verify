ABOUT THE PROJECT

Meet LINKVERIFY.

An academic mini project exploring how AI concepts can be used to improve link awareness and online safety.

OUR MISSION

Verify first. Click later.

LINKVERIFY is designed to provide users with an easy way to examine a website URL before visiting it.

The project combines frontend technologies, backend development, database concepts and AI-based analysis ideas into one system.
